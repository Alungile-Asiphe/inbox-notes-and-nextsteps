# HerWork AI

Redesign my AI Workplace Productivity Assistant as a cute, elegant and professional web app called WorkMate AI.

DESIGN STYLE:

Use soft blush pink, dusty rose, white and dark plum. Make it feminine, modern, welcoming and polished, with rounded cards, subtle shadows, small sparkle details and clean readable fonts. Avoid making it look childish.

DASHBOARD:

Create a beautiful welcome section saying "Make today a little easier." Add the subtitle "Less stress, more getting things done." Show three feature cards with attractive icons.

FEATURE 1 — EMAIL MAGIC:

Users enter the purpose, recipient and details of an email. They select Formal, Friendly or Persuasive. Generate an editable email with a subject line and copy button.

FEATURE 2 — MEETING NOTES:

Users paste meeting notes. Organise them into a summary, key decisions, action items, responsible people and deadlines. Never invent information that is missing.

FEATURE 3 — TASK PLANNER:

Users enter tasks, deadlines and estimated durations. Organise tasks by priority and create a suggested daily schedule. Let users mark tasks as complete.

LAYOUT:

Use a left sidebar on desktop and easy navigation on mobile. Include Dashboard, Email Magic, Meeting Notes and Task Planner. Keep the layout responsive and accessible.

FUNCTIONALITY:

Make navigation, forms, buttons, editing and copying work. Use clearly labelled demo responses only when real AI is not connected. Explain what is needed to enable real AI generation.

RESPONSIBLE AI:

Display a small, clear disclaimer that AI can make mistakes and users should verify outputs. Do not expose API keys in frontend code.

IMPORTANT:

Keep this as ONE integrated workplace productivity application with all three features. Preserve any existing working functionality where possible. First focus on the visual redesign and working interface.
